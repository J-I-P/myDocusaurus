# Docusaurus 建站指南

使用 Docusaurus 建立現代化的文件網站和技術部落格。

## 什麼是 Docusaurus？

Docusaurus 是 Facebook 開源的靜態網站生成器，專為建立文件網站設計：

- **現代化設計** - 響應式、深色模式支持
- **React 基礎** - 可以輕鬆整合 React 組件
- **多語言支持** - 國際化功能完整
- **SEO 優化** - 搜尋引擎友好
- **部署簡單** - 支援多種部署平台

## 特色功能

### 文件系統
- **自動導航** - 根據文件結構生成側邊欄
- **版本管理** - 支持多版本文檔
- **全文搜索** - 整合 Algolia 搜索

### 部落格系統
- **作者管理** - 多作者支持
- **標籤系統** - 內容分類組織
- **RSS 訂閱** - 自動生成 feed

### 擴展性
- **自定義頁面** - React 組件頁面
- **插件生態** - 豐富的社群插件
- **主題系統** - 彈性的視覺客製化
