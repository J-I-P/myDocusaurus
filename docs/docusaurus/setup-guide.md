# Docusaurus 建站完整指南

記錄使用 Docusaurus 建立技術部落格和文件網站的完整過程，包含初始化、配置和部署。

## 🚀 快速開始

### 環境準備

確保你的開發環境滿足以下要求：

- **Node.js** 版本 20.0 或以上
- **npm** 或 **yarn** 套件管理器
- **Git** 版本控制

### 初始化專案

```bash
# 使用官方模板創建專案
npx create-docusaurus@latest my-website classic --typescript

# 進入專案目錄
cd my-website

# 安裝依賴套件
npm install

# 啟動開發服務器
npm start
```

專案將在 `http://localhost:3000` 啟動。

## ⚙️ 基本配置

### 網站資訊設定

編輯 `docusaurus.config.ts` 檔案：

```typescript
const config: Config = {
  title: 'ypin.dev',
  tagline: '分享技術筆記與生活思考的角落',
  favicon: 'img/favicon.ico',

  // 設定網站 URL（用於部署）
  url: 'https://nicole_jiang.github.io',
  baseUrl: '/myDocusaurus/',

  // GitHub Pages 設定
  organizationName: 'nicole_jiang',
  projectName: 'myDocusaurus',

  // 國際化設定
  i18n: {
    defaultLocale: 'zh-TW',
    locales: ['zh-TW', 'en'],
  },

  // 導覽列設定
  navbar: {
    title: 'ypin.dev',
    logo: {
      alt: 'Site Logo',
      src: 'img/logo.svg',
    },
    items: [
      {
        type: 'docSidebar',
        sidebarId: 'tutorialSidebar',
        position: 'left',
        label: '技術文件',
      },
      {to: '/blog', label: '部落格', position: 'left'},
      {
        href: 'https://github.com/nicole_jiang/myDocusaurus',
        label: 'GitHub',
        position: 'right',
      },
    ],
  },
};
```

### 側邊欄配置

Docusaurus 預設使用自動生成的側邊欄，但你也可以手動配置 `sidebars.ts`：

```typescript
const sidebars: SidebarsConfig = {
  // 自動生成側邊欄（推薦）
  tutorialSidebar: [{type: 'autogenerated', dirName: '.'}],

  // 或手動配置
  /*
  tutorialSidebar: [
    'intro',
    {
      type: 'category',
      label: '前端開發',
      items: ['frontend/react-basics', 'frontend/javascript-tips'],
    },
  ],
  */
};
```

## 📝 內容管理

### 文件結構

```
docs/
├── intro.md              # 文件首頁
├── frontend/              # 前端開發分類
│   ├── _category_.json    # 分類設定
│   ├── intro.md          # 分類介紹
│   └── react-basics.md   # 具體文章
├── backend/               # 後端開發分類
└── tools/                 # 開發工具分類

blog/
├── authors.yml            # 作者資訊
├── tags.yml              # 標籤定義
└── 2026-02-25-post.md    # 部落格文章
```

### 文件 Frontmatter

每個 Markdown 檔案開頭的 YAML 設定：

```yaml
---
sidebar_position: 1        # 側邊欄位置
title: 自訂標題           # 覆蓋預設標題
description: 頁面描述     # SEO 描述
keywords: [react, hooks]  # SEO 關鍵字
---
```

### 部落格文章設定

```yaml
---
slug: article-slug         # 自訂 URL
title: 文章標題
authors: [ypin]           # 作者（在 authors.yml 中定義）
tags: [react, frontend]   # 標籤（在 tags.yml 中定義）
---
```

### 分類設定檔

`_category_.json` 用於配置資料夾分類：

```json
{
  "label": "前端開發",
  "position": 2,
  "link": {
    "type": "generated-index",
    "description": "前端開發相關技術文件"
  }
}
```

## 🎨 主題客製化

### 自訂 CSS

編輯 `src/css/custom.css`：

```css
/* 自訂主色調 */
:root {
  --ifm-color-primary: #2e8555;
  --ifm-color-primary-dark: #29784c;
  --ifm-color-primary-darker: #277148;
}

/* 暗色模式 */
[data-theme='dark'] {
  --ifm-color-primary: #25c2a0;
}

/* 自訂樣式 */
.hero__title {
  font-size: 3rem;
}
```

### 自訂組件

在 `src/components/` 中創建 React 組件：

```typescript
// src/components/CustomComponent.tsx
export default function CustomComponent() {
  return (
    <div className="custom-component">
      <h2>自訂組件</h2>
    </div>
  );
}
```

## 🚀 部署流程

### GitHub Pages 部署

1. **推送代碼到 GitHub**：
```bash
git add .
git commit -m "Initial Docusaurus setup"
git push origin main
```

2. **配置 GitHub Pages**：
   - 前往 Repository Settings > Pages
   - 選擇 Source: GitHub Actions
   - 推送時會自動觸發部署

3. **自動部署**：
```bash
npm run deploy
```

這個指令會：
- 構建靜態檔案
- 推送到 `gh-pages` 分支
- 自動部署到 GitHub Pages

### 其他部署選項

- **Vercel**: 連接 GitHub 自動部署
- **Netlify**: 拖拽部署或 Git 整合
- **自託管**: 使用 `npm run build` 生成靜態檔案

## 🔧 進階功能

### 搜尋功能

添加 Algolia DocSearch：

```typescript
// docusaurus.config.ts
themeConfig: {
  algolia: {
    appId: 'YOUR_APP_ID',
    apiKey: 'YOUR_SEARCH_API_KEY',
    indexName: 'YOUR_INDEX_NAME',
  },
}
```

### 多語言支援

```typescript
i18n: {
  defaultLocale: 'zh-TW',
  locales: ['zh-TW', 'en'],
},
```

### 版本管理

```bash
npm run docusaurus docs:version 1.0.0
```

### 離線支援（PWA）

```bash
npm install @docusaurus/plugin-pwa
```
