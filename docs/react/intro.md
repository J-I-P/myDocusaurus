# React 技術專區

深入學習 React 前端框架，從基礎概念到進階應用的完整指南。

## 🎯 學習目標

React 是目前最受歡迎的前端框架之一，這裡記錄了從入門到精通的學習路徑：

- **核心概念** - JSX、組件、Props、State
- **Hooks 系統** - useState、useEffect、自定義 Hooks
- **狀態管理** - Context API、Redux、Zustand
- **性能優化** - memo、useMemo、useCallback
- **測試策略** - Jest、React Testing Library
- **生態系統** - Next.js、React Router、UI 庫
